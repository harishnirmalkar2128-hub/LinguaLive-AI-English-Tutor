# TalkWithLumi – AI English Speaking Tutor

An AI-powered web application that helps users improve their English speaking skills through interactive voice-based conversations.

## 🚀 Live Demo
https://voice-tutor-ai-8.emergent.host

## ✨ Features
- 🎤 Real-time voice conversations
- 🤖 AI-powered responses
- 📚 English speaking practice
- 📱 Responsive design
- ⚡ Easy-to-use interface

## 🛠️ Tech Stack
- Emergent AI
- AI Voice Interaction
- Speech Recognition
- Web Application
