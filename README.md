# 💬 TalkWithLumi – AI English Speaking Tutor

An AI-powered web application that helps users improve their English speaking skills through interactive voice and text conversations with real-time feedback.

---

## 🚀 Live Demo
🔗 **Try it here:** [https://voice-tutor-ai-8.emergent.host](https://voice-tutor-ai-8.emergent.host)

---

## ✨ Features
* 🎤 **Real-Time Voice Conversations:** Practice natural English speaking with instant audio responses.
* ⚡ **Live Grammar Correction:** Detects grammar, pronoun, and syntax mistakes during chats.
* 🤖 **Interactive AI Tutor (Lumi):** Engaging conversational AI tailored to boost language confidence.
* 📱 **Responsive & Clean UI:** Simple, intuitive design with visual badges for easy navigation.

---

## 🛠️ Tech Stack
* **Framework:** Emergent AI
* **Voice Integration:** Speech Recognition & AI Voice Interaction
* **Platform:** Web Application
